## 🎮 如何開始遊玩

本遊戲採用純前端 HTML5 + Canvas + Web Audio API 打造，**完全零套件依賴、不需連上外網，支援 100% 離線使用**。

### 方式一：直接用瀏覽器開啟（最簡單）
直接在檔案總管中雙擊點開 **`index.html`**，即可使用 Chrome、Edge、Safari 或 Firefox 暢玩！

### 方式二：平板 / 班級大屏白板教學
可透過區域網路或放置於學校網頁空間，學生使用 Chromebook、iPad 或觸控大螢幕直接點擊畫面上的質數按鈕即可發射！

## 📚 數學教學核心概念

1. **短除法動態視覺化**：
   - 每發射一顆正確質因數，怪獸體內的數值立即相除縮小（例：$60 \rightarrow 30 \rightarrow 15 \rightarrow 5 \rightarrow 1$）。
   - 當數值縮小到 **1** 時完全分解炸裂，並跳出完整標準分解式（如 $60 = 2^2 \times 3 \times 5$）。

2. **倍數判別法即時回饋**：
   - 底部按鈕附帶「偶數必除」、「各數字和」、「尾數0或5」等速記口訣。
   - 若誤射不能整除的質數（例如對 20 射 7），砲彈會彈刀金屬撞擊，並即時提醒「20 不能被 7 整除！」，引導學生自我修正。

3. **三種遊戲模式**：
   - 🚀 **關卡模式**：由淺入深共 5 波，每波最後出現高位數 BOSS 魔王（如 180、210、360 等），刺激度極高。
   - ⚡ **無盡挑戰模式**：快節奏連續出怪，適合高手學生挑戰極限連擊與最高分排行榜。
   - 🌱 **自由練習模式**：基地護盾無限，無失敗壓力，適合剛學質因數分解、需要時間慢慢心算的孩子。

4. **結算學習履歷清單**：
   - 結算時會完整列出本局所分解過的所有數字及其標準分解式，便於教師課堂檢視與學生訂正。

## 🏆 班級跨裝置即時線上排行榜 (Google 試算表串接)

本遊戲支援**跨平板即時線上排行榜**，無須租用伺服器或資料庫，老師使用自己的 **Google 試算表 + Google Apps Script** 即可在 3 分鐘內建立全班共用榮譽榜：

1. **建立試算表**：在 Google 雲端硬碟建立空白試算表，命名為「質因數保衛戰-班級排行榜」。
2. **貼上後端程式碼**：點選【擴充功能】>【Apps Script】，複製貼上專案中的 `google_apps_script.js` 全部內容。
3. **部署為網頁應用程式**：點選右上角【部署】>【新增部署作業】，選擇【網頁應用程式】，執行身分選【我】，誰可以存取選【任何人】(Anyone)。
4. **啟用連線**：
   - **方式 A（免重推）**：點擊遊戲內「查看英雄榜」>「⚙️ 雲端設定」貼上網址並點擊「測試連線並儲存」。
   - **方式 B（全班自動同步）**：將網址填入 `config.js` 中的 `cloudApiUrl: "..."` 並推上 GitHub，全班所有 iPad 只要開啟網頁即可全自動連線！
