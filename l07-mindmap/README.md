# 國語六上 第七課《跟著公共藝術去旅行》數位化心智圖思考單

> 專為國小高年級（生生用平板）設計的「課文同步導讀 ＋ 8 字關鍵詞提取 ＋ 動態心智圖生成 ＋ Google 試算表自動收卷」互動式網頁學習單。

---

## 🌟 教學設計與系統亮點

1. **左閱課文、右解任務（雙欄連動模式）**：
   - 左側內建第七課《跟著公共藝術去旅行》**第 1 到 6 段完整課文**與自然段標籤。
   - 點擊右側問題時，左側課文自動平滑滾動並**發亮高亮**對應段落，引導學生「邊讀課文、邊找線索」。
   - 支援字體放大（A+）與縮小（A-），保護學生視力。

2. **嚴格落實「8 個字以內精煉關鍵詞」**：
   - 題目輸入框自帶**「即時字數計數器」**。
   - 學生輸入超過 8 個字時，計數器會變成紅色警示 `(⚠️ 請精簡在8字內)`，幫助學生戒除整句抄課文的習慣，學會提取核心概念（名詞＋動詞）。

3. **雙重資料保存機制（100% 不怕掉資料）**：
   - **本機自動暫存（LocalStorage）**：學生在任何欄位打字時即時暫存，就算誤觸重新整理或平板沒電關機，重新開啟進度完全保留。
   - **雲端自動收卷（Google 試算表）**：學生完成後按下「送出學習單」，全班各題回答、三方比較表、心智圖大綱自動寫入老師的 Google 試算表。

4. **即時動態生成專屬心智圖（Canvas）**：
   - 系統依據學生提取的關鍵詞，自動繪製出以《跟著公共藝術去旅行》為中心的樹狀心智圖。
   - 支援**「一鍵下載心智圖圖片 (PNG)」**與**「複製心智圖大綱文字」**。

5. **無縫銜接 Q12 Padlet 小組發表**：
   - 提供「前往 Padlet 發表牆」快捷鈕，學生下載心智圖後，可直接貼到全班的 Padlet 看板進行觀摩與口說發表。

## 🛠️ 老師端 1 分鐘快速設定（Google 試算表自動收卷）

只要簡單 3 步驟，即可讓全班學生的作答自動彙整到您的 Google 試算表：

### 第一步：建立 Google 試算表與貼上腳本
1. 前往 [Google 雲端硬碟](https://drive.google.com/)，建立一個全新的 Google 試算表，命名為例如：`國語第七課心智圖學習單_作答收集`。
2. 點選試算表上方選單的 **「擴充功能」 ➔ 「Apps Script」**。
3. 清空編輯器裡的預設程式碼，打開本專案的 `google-apps-script.js`，將全部內容複製並貼上到 Apps Script 中。

### 第二步：部署為網頁應用程式 (Web App)
1. 點擊右上角藍色按鈕 **「部署」 ➔ 「新部署」**。
2. 點選左側齒輪圖示，選擇 **「網頁應用程式」**：
   - **說明**：填寫「收集學習單」
   - **執行身分**：選擇「我 (Me)」
   - **誰可以存取**：務必選擇 **「所有人 (Anyone)」**（這樣學生提交才不會被權限擋住）。
3. 點擊「部署」，首次部署會跳出審查權限：
   - 點「審查權限」➔ 選擇您的 Google 帳號 ➔ 點「進階」➔ 點「前往 (不安全)」➔ 點「允許」。
4. 部署完成後，複製畫面上顯示的 **「網頁應用程式網址」**（格式為 `https://script.google.com/macros/s/AKfycb.../exec`）。

### 第三步：填入學習單設定
1. 用瀏覽器開啟 `index.html`。
2. 點擊右上角的 **「⚙️ 老師設定」**。
3. 把剛才複製的網址貼到 **「Google Apps Script Web App 網址」** 欄位中，並可選填您的 **Padlet 看板網址**，點擊「儲存設定」即可！

## 📱 學生課堂操作流程

1. **進入網頁**：在頂部輸入 **座號** 與 **姓名**。
2. **關卡一（課文初探）**：默讀全文、標出自然段（共 6 段），回答文體與意義段劃分（Q1~Q3）。
3. **關卡二（線索提煉）**：點擊問題自動定位課文，挑戰提煉 8 字以內的關鍵詞（Q4~Q9）。
4. **關卡三（作品對照）**：對比《大地之書》、《花間小鹿》、《分合隨緣》三件作品的地點、外觀與涵義表格（Q10）。
5. **關卡四（總結與心智圖）**：寫下體悟（Q11），預覽專屬心智圖並點擊 **「📥 下載心智圖圖片 (PNG)」**。
6. **關卡五（送出與發表）**：點擊 **「📤 送出學習單給老師」**（資料寫入試算表），再點 **「📌 前往 Padlet 發表牆」** 上傳成果（Q12）。
