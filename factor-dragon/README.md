# 貪吃因數龍：因數全搜集大冒險 (Factor Dragon)
### 專為國小中高年級設計的因數練習教具遊戲

本遊戲依據國小中高年級（四、五年級）數學「因數與倍數、不遺漏成對找因數、整除心算概念」教學目標全新打造：結合經典貪吃蛇走位玩法與因數圖鑑搜集機制，引導孩子在盤面上辨識目標數字的「所有因數」，避開非因數干擾，集齊所有因數即可進化神龍！

---

## 🎮 遊戲特色

1. **因數全搜集與圖鑑展示櫃（Factor Collection Shelf）**：
   - 頂部展示櫃清楚呈現目標數字的所有因數格子。
   - 吃到正確因數時，對應格子瞬間點亮為翠綠金光，激勵學童「一個都不漏找」。
2. **即時整除教育反饋（Instant Diagnostic Feedback）**：
   - 吃到因數：即時彈出 `24 ÷ 6 = 4 (整除！)` 並加分成長。
   - 誤吃非因數：即時彈出 `24 ÷ 5 = 4 餘 4 (不能整除，不是因數！)`，強化除法餘數與因數之連結。
3. **因數成對與質數暴擊（Prime Factor & Pairs）**：
   - 過關結算自動整理「成對乘積算式」（如 $24 = 1 \times 24 = 2 \times 12 = 3 \times 8 = 4 \times 6$）。
   - 吞食質因數（如 2、3）享有雙倍暴擊加分！
4. **友善防挫折機制（Friendly Wrap-around Grid）**：
   - 支援邊界穿越（由另一側穿出），讓小學生的專注力留在「心算整除」而非硬核閃避反射。
5. **四大神龍進化（Dragon Evolution Progression）**：
   - 基礎之森（青木幼龍）➔ 珊瑚之海（碧海角龍）➔ 熔岩之谷（烈焰飛龍）➔ 神龍之巔（幻彩金甲神龍）。
6. **平板與觸控雙支援**：
   - 支援滑動手勢（Swipe）與螢幕專屬大尺寸十字虛擬方向鍵（D-Pad），電腦端亦完全支援 WASD / 方向鍵。
7. **100% 離線純前端運作**：
   - 純 HTML5 Canvas + Web Audio API 合成音效與 BGM，零外部相依性，免連外網即開即玩。

## 🎯 三種遊戲模式

| 模式名稱 | 適合對象 | 特色說明 |
| :--- | :--- | :--- |
| 🗺️ **冒險闖關模式** | 課堂循序漸進練習 | 四大世界共 16 關（目標數涵蓋 12 ~ 100），循序漸進解鎖神龍進化 |
| ⚡ **60秒極速衝刺** | 競速挑戰、課堂競賽 | 限時 60 秒極速心算，吃對 +3 秒，集齊 +15 秒狂歡！ |
| 🌱 **自訂練習模式** | 弱點特訓、作業複習 | 可自由輸入任意目標數字（4 ~ 120），針對特定數字進行地毯式因數練習 |

## 📁 檔案結構

- **`index.html`**：遊戲主頁面、HUD 抬頭顯示器、因數圖鑑展示櫃、虛擬十字盤與彈窗。
- **`style.css`**：神龍霓虹冒險風格樣式與響應式排版。
- **`game.js`**：因數演算法、神龍身體運動、果實生成與教學即時診斷回饋。
- **`audio.js`**：Web Audio API 自行合成的清脆吞食音效、質數閃亮音效與神龍冒險背景音樂。
