## ✨ 核心特色與功能

### 1. 🔄 自動同步 Padlet 聯絡簿
* 自動連線至 Padlet 看板（`sec_ZNL0qaEGm3YlqP1d` 聯絡簿區段）。
* 自動解析最新一天的作業清單（如數習、字形七字詩、數重）。
* 智慧過濾非作業提醒（如穿班服、考直笛、期中考提醒）。
* 隔天發布新聯絡簿時，自動跳出更新提示，一鍵建立新一日清點。

### 2. ⚡ 極速反向點選（組長專用）
* **預設全班皆為「已交（綠燈）」**，組長收完作業上台**只需點 1~2 位未繳交的同學（亮紅燈 ❌）**，3 秒登記完畢回座。
* 座號 1 到 26 號超大方塊，觸控螢幕與滑鼠皆極好點選。
* 點擊內建清脆音效回饋。

### 3. 🩺 晨間請假先鎖定
* 一早點選「🩺 設定請假」，請假同學在所有作業中自動標為「灰色請假」，不計入缺交名單，避免組長誤記。

### 4. 📢 黑板大看板模式（投影展示）
* 按下 `F11` 進入全螢幕大看板模式。
* 超大字體並列顯示各科未交座號，坐在教室最後一排的同學也一目了然。
* 當某科 100% 全數繳齊時，自動觸發滿版彩帶煙火動畫（Confetti）與慶祝音效 🎉！

### 5. 📋 一鍵複製 LINE 催繳通知
* 點擊「📋 複製未交名單」，自動產生格式工整的文字，方便直接貼到 LINE 班級群組或留存紀錄。

### 6. 💾 離線優先與瀏覽器自動存檔
* 免伺服器資料庫，所有點選狀態即時存於本機瀏覽器（LocalStorage），換日自動按日期備份，電腦關機或斷電資料不遺失。

## 🛠️ 本地開發與使用

此專案為純前端單頁應用（SPA），無需安裝任何依賴套件或建立 Node.js 伺服器：

1. 下載或複製本專案：
   ```bash
   git clone https://github.com/ted710317-cloud/607-homework-board.git
   ```
2. 直接雙擊 `index.html`，以 Chrome 或 Edge 瀏覽器開啟即可開始使用。
