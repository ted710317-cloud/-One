# 糖果雨消消樂：九九乘法大冒險 (Candy Multiplier Drop)
### 專為國小低年級設計的九九乘法精熟練習遊戲

---

## 🍬 遊戲設計特色

本遊戲依據國小低年級數學「九九乘法精熟與心算反射」教學目標設計，採用 **俄羅斯方塊掉落危機感 × 泡泡消消樂連鎖爆炸** 核心玩法：

1. **題目保證盤面必有解**：
   - 系統動態出題時，即時掃描當前盤面現存糖果數字，保證孩子眼前一定能找到正確答案；若盤面剛好缺乏，系統會瞬間點石成金轉化一顆糖果，絕不會讓孩子陷入無解困境。
2. **同色連鎖大爆炸 (Connected Blast)**：
   - 點擊正確答案糖果時，相鄰同色糖果會一併連鎖爆破消除！引導孩子邊算乘法邊觀察盤面同色糖果分佈，大幅增添策略性與爽快感。
3. **FEVER 狂熱彩虹模式**：
   - 連擊不間斷即可集滿狂熱能量條，觸發 8 秒全彩糖果雨，分數加倍、聲光效果十足。
4. **具象化「點子陣列小幫手」**：
   - 點擊右上角「💡」按鈕，即時顯示乘法算式的點子矩陣（例如 $7 \times 8$ 呈現 7 顆一排、共 8 排的糖果點），幫助具象思考型學童建構概念。
5. **平板專屬「Q 萌虛擬鍵盤」雙操作模式**：
   - 專為 iPad、Android 平板與觸控螢幕打造大尺寸果凍數字鍵盤（1~9, 0, C 清除, ⌫ 退格）。
   - **雙操作模式**：學生可以直接觸控點擊盤面上的正確糖果，也可以在鍵盤上敲入答案（打完位數自動判定！），手感流暢無比。
   - 支援頂部「⌨️」一鍵隱藏/開啟鍵盤，並同步支援電腦筆電的實體數字鍵。
6. **學習診斷履歷結算**：
   - 每局結束後完整列出「反射神速題目（<2秒）」與「建議加強題目（答錯或思考>3.5秒）」，方便老師與家長掌握孩子的乘法盲區（如 $7 \times 8 = 56$、$6 \times 7 = 42$ 等易錯題目）。

## 🎮 如何開始遊玩

本遊戲採用純前端 **HTML5 Canvas + Web Audio API** 打造，**零外部套件依賴、免連外網、支援 100% 離線遊玩**。

### 方式一：直接在電腦上雙擊開啟
直接點擊專案資料夾內的 **`index.html`**，即可使用 Chrome、Edge、Firefox 或 Safari 暢玩。

### 方式二：平板 / 觸控白板大螢幕教學
透過區域網路或放置於學校教學網站，學生使用 iPad、Chromebook 或電子白板直接觸控點擊即可遊玩。

| 模式名稱 | 適合對象 | 特色說明 |

## 💣 輔助道具

- 💣 **彩虹炸彈**：直接引爆盤面上某一種顏色的所有糖果，瞬間化解堆疊危機。
- ❄️ **冰凍時鐘**：冰凍時間 5 秒鐘，暫停新糖果雨下落，爭取充裕心算時間。
- 🔄 **換一題**：遇到卡關題目時，一鍵重新抽換題目。
