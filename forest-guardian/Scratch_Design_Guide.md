# 🌲 Scratch AI 雙關卡互動遊戲：程式設計說明書
## 作品名稱：森林守護者：大自然復興之旅 (Forest Guardian)

> **設計理念與教育目標：**  
> 本作品依據教育部與科技教育競賽指標設計，讓學生在寓教於樂的雙關卡體驗中，深刻體會森林生態系統的脆弱與復育的重要性。  
> - **第一關（反應與體驗）**：透過快節奏的動作閃避與資源收集，體驗守護森林抵抗天災人禍的迫切性。運用**亂數、碰撞偵測、座標運算、螢幕震動回饋與 AI 視訊控制**。  
> - **第二關（選擇與策略）**：化身生態復育指揮官，針對水土流失、外來入侵種、垃圾污染等不同環境困境，透過**條件分支與狀態變數**做出適當復育決策，親眼見證生態環境動態復甦。

---

## 一、 系統架構與變數清單 (Variables & Lists)

在 Scratch 專案中，請先建立以下變數與廣播訊息：

### 1. 全域變數 (Global Variables - 適用於所有角色)
| 變數名稱 | 初始值 | 說明 |
| :--- | :--- | :--- |
| `森林生機值` | 50 | 遊戲核心生命指數 (範圍 0 ~ 100) |
| `遊戲倒數` | 30 | 第一關限時倒數秒數 |
| `當前關卡` | 1 | 記錄目前關卡 (1: 第一關, 2: 第二關) |
| `震動強度` | 0 | 控制舞台震動幅度 (落石擊中時觸發) |
| `當前環境困境` | 1 | 第二關當前診斷的災情代碼 (1: 坡地流失, 2: 外來種, 3: 水源污染) |
| `復育策略選擇` | 0 | 玩家在第二關選取的行動代碼 |

### 2. 廣播訊息 (Broadcast Messages)
- `開始第一關`：重置變數，啟動第一關掉落物生成。
- `第一關通關`：觸發成功音效，切換第一關結算畫面。
- `開始第二關`：切換森林現場背景，載入環境診斷問題。
- `觸發地動震動`：落石擊中時廣播，讓背景舞台產生晃動。
- `大圓滿勝利`：全數復育完畢，彈出知識卡與獲勝徽章。
- `遊戲失敗`：生機歸零或時間到未達標。

## 二、 第一關【反應與體驗】Scratch 程式積木組

### 角色一：守護精靈 (玩家操控主體)
* **造型**：正常狀態、受傷閃爍狀態。
* **AI 視訊互動設計（擴充功能：視訊偵測 Video Sensing）**：
  若使用 AI 模式，利用攝影機偵測玩家手勢或身體位置，角色隨之移動。

```scratch
當綠旗被點擊
變數 [當前關卡 v] 設為 1
變數 [森林生機值 v] 設為 50
變數 [遊戲倒數 v] 設為 30
定位到 x: (0) y: (-140)
開啟視訊偵測擴充
將 [視訊透明度 v] 設為 (50)

當收到訊息 [開始第一關 v]
重複執行直到 <(當前關卡) > 1>
    // --- 模式 A：鍵盤控制 ---
    如果 <鍵盤 [向左鍵 v] 被按下?> 那麼
        x 改變 (-10)
    如果 <鍵盤 [向右鍵 v] 被按下?> 那麼
        x 改變 (10)
    
    // --- 模式 B：AI 視訊體感偵測 (若有鏡頭) ---
    如果 <([角色1 v] 的視訊動作) > (20)> 那麼
        如果 <(滑鼠的 x 座標) < (x 座標)> 那麼
            x 改變 (-8)
        否則
            x 改變 (8)
        結束
    結束

    // 舞台邊緣限制保護
    如果 <(x 座標) > (210)> 那麼 定位到 x: (210) y: (-140) 結束
    如果 <(x 座標) < (-210)> 那麼 定位到 x: (-210) y: (-140) 結束
結束
```

### 角色二：落下物品（雨滴、樹苗、火焰、落石 - 分身機制）
* **設計要點**：完全符合評量之**「物品位置、種類或移動速度，必須運用亂數積木設計」**。

```scratch
當收到訊息 [開始第一關 v]
隱藏
重複執行直到 <(當前關卡) 不等於 1>
    等待 (隨機取數 (0.5) 到 (1.0)) 秒
    建立 [自己 v] 的分身
結束

當分身產生
外觀換成 (隨機取數 (1) 到 (4)) // 造型1:水滴, 造型2:樹苗, 造型3:火焰, 造型4:落石
變數 [分身速度] 設為 (隨機取數 (4) 到 (8)) // 亂數速度
定位到 x: (隨機取數 (-210) 到 (210)) y: (180) // 亂數位置
顯示

重複執行直到 <<碰到 [邊緣 v] ?> 或 <碰到 [守護精靈 v] ?>>
    y 改變 (0 - (分身速度))
    造型旋轉 (隨機取數 (-3) 到 (3)) 度
結束

如果 <碰到 [守護精靈 v] ?> 那麼
    如果 <(造型編號) = 1> 那麼  // 水滴：益品
        撥放音效 [Water Drop v]
        變數 [森林生機值 v] 改變 (10)
    結束
    如果 <(造型編號) = 2> 那麼  // 原生樹苗：珍品
        撥放音效 [Chime v]
        變數 [森林生機值 v] 改變 (20)
    結束
    如果 <(造型編號) = 3> 那麼  // 火焰：危險品
        撥放音效 [Sizzle v]
        變數 [森林生機值 v] 改變 (-15)
    結束
    如果 <(造型編號) = 4> 那麼  // 落石：大危機 (具備震動效果)
        撥放音效 [Low Boing v]
        廣播訊息 [觸發地動震動 v]
        變數 [森林生機值 v] 改變 (-20)
    結束
結束
刪除此分身
```

### 角色三 / 舞台背景：落石撞擊地動晃動程式碼 (評審亮點)
當落石擊中時，舞台或角色必須產生短暫晃動效果：

```scratch
當收到訊息 [觸發地動震動 v]
重複執行 (6) 次
    x 改變 (隨機取數 (-8) 到 (8))
    y 改變 (隨機取數 (-6) 到 (6))
    等待 (0.02) 秒
結束
定位到 x: (0) y: (0) // 震動完精準復位
```

## 三、 第二關【選擇與策略】Scratch 程式積木組

### 核心玩法：情境診斷 ➔ 三選一行動 ➔ 生態動態復甦
第二關設計至少 **3 種森林復育選項**（種植原生樹苗、清除外來入侵植物、清理垃圾）。

```scratch
當收到訊息 [開始第二關 v]
換成背景 [受災荒山背景 v]
變數 [當前環境困境 v] 設為 1

重複執行直到 <(森林生機值) >= 100>
    如果 <(當前環境困境) = 1> 那麼
        說出 [目前山坡土壤裸露流失！該怎麼辦？(按 1 植深根樹 / 按 2 除草 / 按 3 撿垃圾)]
    結束
    如果 <(當前環境困境) = 2> 那麼
        說出 [外來種小花蔓澤蘭爬滿樹冠！大樹快悶死了！請選擇對策！]
    結束
    如果 <(當前環境困境) = 3> 那麼
        說出 [溪流遭塑膠廢棄物堵塞污染！請選擇對策！]
    結束

    等待直到 <<鍵盤 [1 v] 被按下?> 或 <<鍵盤 [2 v] 被按下?> 或 <鍵盤 [3 v] 被按下?>>>

    // 判斷按鍵與決策適配度
    如果 <<(當前環境困境) = 1> 且 <鍵盤 [1 v] 被按下?>> 那麼
        撥放音效 [Magic Spell v]
        變數 [森林生機值 v] 改變 (25)
        廣播訊息 [長出大樹與綠草 v]
        變數 [當前環境困境 v] 改變 (1)
    否則
        如果 <<(當前環境困境) = 2> 且 <鍵盤 [2 v] 被按下?>> 那麼
            撥放音效 [Magic Spell v]
            變數 [森林生機值 v] 改變 (25)
            廣播訊息 [開出鮮花與蝴蝶 v]
            變數 [當前環境困境 v] 改變 (1)
        否則
            如果 <<(當前環境困境) = 3> 且 <鍵盤 [3 v] 被按下?>> 那麼
                撥放音效 [Victory Fanfare v]
                變數 [森林生機值 v] 改變 (25)
                廣播訊息 [清澈溪流與野生動物回歸 v]
                變數 [當前環境困境 v] 改變 (1)
            否則
                撥放音效 [Buzz v]
                說出 [方針不對！請針對目前問題對症下藥！] 歷時 (2) 秒
                變數 [森林生機值 v] 改變 (-5)
            結束
        結束
    結束
    等待 (1) 秒
結束

廣播訊息 [大圓滿勝利 v]
換成背景 [綠意盎然森林樂園 v]
```
