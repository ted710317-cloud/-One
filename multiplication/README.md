# 九九乘法砲台保衛戰 (Multiplication Cannon Defender)
### 專為國小中年級設計的九九乘法精熟練習教具遊戲

本遊戲參考經典太空保衛戰的形式，依據教育部國小中年級數學「九九乘法精熟心算與反向乘除填空」教學目標全新打造：怪獸帶著未完成的乘法護盾（例如 `2 × [ ] = 4`、`7 × [ ] = 56`）從星空上方落下，防衛官必須精準心算，利用下方的數字鍵盤（1~9）瞄準射擊，將正確的數字填入 `[ ]`，使算式成立消除怪獸！

---

## 🎮 如何開始遊玩

本遊戲採用純前端 **HTML5 + Canvas + Web Audio API** 打造，**完全零外部套件依賴、不需連外網，支援 100% 離線使用**。

### 方式一：直接用瀏覽器開啟（最簡單）
直接在檔案總管中雙擊點開 **`index.html`**，即可使用 Chrome、Edge、Safari 或 Firefox 暢玩！

### 方式二：平板 / 班級大屏白板教學
可透過區域網路或放置於學校網頁空間（如 GitHub Pages），學生使用 Chromebook、iPad 或觸控大螢幕直接點擊畫面上的數字砲彈即可發射！

## 📚 數學教學核心亮點

1. **反向乘除填空核心（Missing Factor Bridging to Division）**：
   - 題目形式為 `a × [ ] = c`（例如 `2 × [ ] = 4`、`7 × [ ] = 56`、`9 × [ ] = 72`）。
   - 不僅能鍛鍊九九乘法的正向心算，更能提早建構「除法是乘法的逆運算」概念，讓中年級學生在學習除法單元時無縫銜接。

2. **即時診斷與彈刀回饋（Instant Corrective Feedback）**：
   - 當射出正確數字（如 `2 × [2] = 4`）：框框瞬間填入數字並散發耀眼綠光，怪獸爆破引發粒子煙火，伴隨連擊音效。
   - 當射出錯誤數字（如對 `2 × [ ] = 4` 誤射 3）：畫面即刻跳出警示氣泡 `2 × 3 = 6 ❌ (應該是 2 × 2 = 4)`，砲彈被防衛盾彈開，怪獸保留讓孩子重新思考，建立自我修正能力。

3. **三種遊戲模式（滿足不同學習進度）**：
   - 🚀 **冒險闖關模式**：循序進階 5 大波次：
     - 第 1 波：2, 3, 5 的乘法（建立信心）
     - 第 2 波：4, 6, 8 的乘法（偶數進階心算）
     - 第 3 波：7, 9 的乘法（國小最易混淆的乘法魔王關）
     - 第 4 波：1~9 全面隨機大亂鬥
     - 第 5 波：菁英怪 + 究極三階九九乘法母艦 BOSS（連續破解 3 題才可消滅！）
   - ⚡ **無盡挑戰模式**：⏱️ 30 秒極速心算，答對補時 +3 秒；10 連擊觸發 🔥 FEVER 雙倍狂熱（補時 +5 秒，分數 x2，全彩特效）；答錯扣 3 秒、撞線扣 5 秒！
   - 🌱 **自由練習模式**：無限護盾、無倒數壓力，更支援**自選練習乘數**（例如只勾選練習 7 與 8 的乘法，專門特訓弱點）。

4. **九九乘法學習診斷歷程（Learning Diagnostics Review）**：
   - 結算時完整列出本局所練習的每一道乘法題目。
   - 依據反應時間精準分級：
     - ⚡ **神速反射**（< 2.0 秒，綠色徽章）
     - 👍 **良好熟練**（2.0 ~ 3.5 秒，藍色徽章）
     - 💡 **建議加強**（> 3.5 秒或曾有答錯嘗試，橘紅色徽章，提醒課後複習）

5. **全班 Google 試算表雲端排行榜（Google Sheets Integration）**：
   - 內建 Google Apps Script 雲端同步架構，全班不同平板或電腦可即時同步最新戰報與英雄榜。
   - 具備防連線撞車排隊鎖定機制與個人最高分去重功能。

## 📁 專案架構

- **`index.html`**：主頁面與遊戲視窗、HUD 抬頭顯示器、底座 1~9 砲台控制台、各功能彈窗。
- **`style.css`**：現代科技霓虹風格樣式，支援電腦、iPad、Android 平板與手機響應式排版。
- **`game.js`**：遊戲核心引擎（怪獸生成、題目邏輯、彈道碰撞、連擊評分、學習履歷統計、排行榜連線）。
- **`audio.js`**：Web Audio API 自行合成的音效與 8-bit 背景音樂，免外部音檔。
- **`config.js`**：全域雲端試算表 API 網址設定。
- **`google_apps_script.js`**：Google 試算表雲端後端部署程式碼。
